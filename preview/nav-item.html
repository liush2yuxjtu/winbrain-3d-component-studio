Nav Itemnav-item

首页顶部的导航按钮，当前项渲染为 25px 圆角胶囊。

Page HeaderNav ItemMode Switch

舞台：首页场景 · 在 1536 × 1024 的 .scene 内按原坐标绝对定位渲染，预览按比例缩放。

Description

首页 .nav 里的按钮，可带 19px 图标。选中态不是颜色变化而是形状变化：未选中项是透明背景的文字按钮，当前项变成有底色的胶囊。这样在复杂的三维背景上，位置感比颜色更可靠。

Variants

VariantUse WhenSelector
Default未选中的页面项.nav button
Active当前页面或当前打开的对话框.nav .active

Props / Properties

PropertyTypeDefaultDescription
heightlength40px按钮高度，图标用 vertical-align:middle 对齐。
gaplength34px（导航）/ 10px（图标与文字）项间距与项内间距是两套值。
border-radiuslength25px仅选中态生效。
aria-current / .activestate—class 负责选中样式，当前项另由 aria-current="page" 暴露给读屏。

States

StateVisualBehavior
Default无背景，文字 14px #f4f5f8（继承 body）hover 无背景变化
Activebackground #282f43，border-radius 25px，min-width 94px 居中，padding 0 24px—
Focusoutline 2px #a6d6ff，offset 6px键盘可达

Accessibility

ROLE

button（原生 <button>），容器 nav 带 aria-label

KEYBOARD

Tab 进入，Enter/Space 触发；focus-visible 有 6px 外扩描边以免贴住胶囊边界

SCREEN READER

由文本内容朗读；图标 svg 无 title，不重复朗读；当前项用 aria-current="page" 暴露

Do's and Don'ts

✅ Do
  • 选中态同时改变形状与背景，避免只靠颜色
  • 图标统一 19px、stroke 1.4、currentColor
❌ Don't
  • 不要用 <a> 假装按钮再补 role
  • 不要在导航项之间混用不同图标尺寸

Code Example

<button class="active" data-home aria-current="page">Home</button>
<button data-open="chat"><svg class="icon">…</svg>AI Chat</button>
