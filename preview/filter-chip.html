Token 审计页的分类筛选胶囊，选中态填实。

SwatchFilter ChipEyebrowPlatform Label

舞台：文档页 · 在 74px 页面头部下的普通内容流里渲染，不需要页面上下文。

Description

一组互斥的分类筛选钮。和首页 control-button 是同一形态（16px 圆角胶囊）但不同语义：这里用 .active class 表达唯一选中，而首页用 aria-pressed。两处圆角值相同，说明 16px 事实上是这个系统的“胶囊档”。

Variants

VariantUse WhenSelector
Default未选中的分类.filters button
Active唯一选中的分类；再点“全部”可复位.filters button.active

Props / Properties

PropertyTypeDefaultDescription
border-radiuslength16px与首页 .control-buttons button 相同，等于未导出的 radius.control。
paddinglength7px 11px与首页控制按钮完全一致。
font-sizelength10px比首页的 11px 小一档。

States

StateVisualBehavior
Default1px #38506d 边，底 #162232，文字 #91a9c9点击切换分类
Active底 #315986，文字 white，边 #77a8e6与搜索框叠加过滤
Focusoutline 2px var(--wb-color-accent)，offset 3px键盘可达

Accessibility

ROLE

容器 role="group" + aria-label="Token 分类"

KEYBOARD

Tab 逐个；Enter/Space 切换

SCREEN READER

朗读分类名；当前选中没有 aria-pressed / aria-current

Do's and Don'ts

✅ Do
  • 第一个胶囊固定为“全部”，提供复位入口
  • 与搜索框组合时用 flex-wrap 兜住窄屏
❌ Don't
  • 不要与搜索框抢占同一行宽度（窄屏要转成纵向）
  • 不要给分类胶囊加图标

Code Example

<div class="filters" role="group" aria-label="Token 分类">
  <button class="active" data-group-filter="全部">全部</button>
  <button data-group-filter="Color">Color</button>
</div>
