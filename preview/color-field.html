Color Fieldcolor-field

原生取色器，26 × 23，无边框，带同行“还原”。

Search FieldNumber FieldCheckboxColor FieldNudge Pad

舞台：编辑器 · 在 body[data-mode="studio"] 的字体与底色上下文中渲染。

Description

组件着色用的原生 input[type=color]。刻意去掉边框和内边距，让色块本身就是控件；右侧固定一个 9px 的“还原”文字按钮，构成“改—撤”的完整闭环。

Variants

VariantUse WhenSelector
Row检查器的“组件色”一行.color-row

Props / Properties

PropertyTypeDefaultDescription
width / heightlength26px / 23px比原生默认更窄，需要显式设置。
border / paddingkeyword0 / 0完全去掉，靠色块本身当控件。
justify-contentkeywordspace-between标签靠左，还原按钮靠右。

States

StateVisualBehavior
Default裸色块 + 左侧 10px 标签点击打开系统取色器
Changed无独立视觉反馈；改动由左侧列表的 .changed 圆点统一表达实时改材质颜色

Accessibility

ROLE

原生 color input

KEYBOARD

Enter 打开系统取色器，方向键调值

SCREEN READER

由包裹式 label 朗读“组件色”

Do's and Don'ts

✅ Do
  • 改动反馈统一交给组件列表的 .changed 圆点
  • 始终并排放一个还原入口
❌ Don't
  • 不要在同一个检查器里放多个取色器（当前只允许一个组件色）
  • 不要给色块加边框和圆角（会与原生控件边缘冲突）

Code Example

<div class="color-row">
  <label>组件色<input type="color" id="tint" value="#9dbeff"></label>
  <button id="clear-tint">还原</button>
</div>
