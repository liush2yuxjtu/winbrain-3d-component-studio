Component List Itemcomponent-list-item

编辑器左侧组件列表的一行：图标、名称、改动圆点与版本号。

Token CardAsset CardMotion CardSmall CardComponent List ItemLayer Card
智能角色4

舞台：编辑器 · 在 body[data-mode="studio"] 的字体与底色上下文中渲染。

Description

一行里压缩了四类信息：家族图标（按 family 换色）、名称、是否被改过（金色 4px 圆点）、以及资产版本。选中态用左侧 2px 内阴影条 + 底色，而不是整行高亮，因为列表项很密。

Variants

VariantUse WhenSelector
Application family应用层组件，图标 #91b9f6.component-glyph
Actor family智能角色，图标 #bb9ff5.component-item[data-family="actor"] .component-glyph
Data family业务对象，图标 #9cbec7.component-item[data-family="data"] .component-glyph
Changed该组件已被编辑过，显示金色圆点.component-item.changed

Accessibility

ROLE

button（宽 100% 的 <button>）

KEYBOARD

Tab 逐行；方向键未接管

SCREEN READER

朗读名称；版本号 .item-version 是相邻文本会被一并读出；选中态由 aria-pressed 暴露；改动状态 .edit-dot 无文本替代

Do's and Don'ts

✅ Do
  • 改动状态用圆点而不是改变整行颜色
  • 按 family 给图标换色，让类别在密集列表里可扫
❌ Don't
  • 不要用颜色深浅表达选中（已有左侧条承担）
  • 不要让版本徽标和改动圆点同时占位（都用 margin-left:auto）
