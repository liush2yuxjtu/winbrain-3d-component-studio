编辑器的成对操作按钮：导出 JSON / 保存模型 PNG、重置 / 恢复。

Explore ButtonControl ButtonPrimary ButtonSecondary ButtonFile ButtonText Button

舞台：编辑器 · 在 body[data-mode="studio"] 的字体与底色上下文中渲染。

Description

两列等宽网格里的次级按钮。深底 #1e2a3b + 描边，与 .primary 形成明确的层级差。因为成对出现，宽度由 1fr 1fr 决定，不设置各自宽度。

Variants

VariantUse WhenSelector
Default成对的次级动作.two-buttons button
Compact同上但用 <span class=compact> 的只读单元（如“适合窗口”）.two-buttons .compact

Props / Properties

PropertyTypeDefaultDescription
grid-template-columnstrack-list1fr 1fr两列等宽。
gaplength7px与圆角 5px 接近，视觉上不散开。
paddinglength9px 4px水平内边距很小，靠 text-align 居中而不是 padding。

States

StateVisualBehavior
Defaultbackground #1e2a3b，1px #3b4b62 边，文字 10px #b0c5e1—
Hoverbackground #2d405c过渡 0.12s（继承全局 button）
Global hover fallback未被 .two-buttons button:hover 覆盖时落到全局 button:hover 的 #2b394d两套 hover 值不一致

Accessibility

ROLE

button

KEYBOARD

Tab 顺序与视觉顺序一致

SCREEN READER

由文字朗读；无图标

Do's and Don'ts

✅ Do
  • 成对使用，两列等宽
  • 文字尽量控制在 6 个汉字以内以适配 4px 水平内边距
❌ Don't
  • 不要在 .two-buttons 里放超过 2 个按钮
  • 不要用第 3 套 hover 底色（当前已存在 #2b394d 与 #2d405c 两套）

Code Example

<div class="two-buttons">
  <button id="export">导出 JSON</button>
  <button id="reset">恢复默认</button>
</div>
