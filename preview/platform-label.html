Platform Labelplatform-label

跟随三维平台的世界空间标签，带板号和层级。

SwatchFilter ChipEyebrowPlatform Label

舞台：首页场景 · 在 1536 × 1024 的 .scene 内按原坐标绝对定位渲染，预览按比例缩放。

Description

三块玻璃平台各有一个跟随标签，位置由 three.js 投影到屏幕坐标后写进 --label-x / --label-y。背景是从左到右淡出的半透明渐变（不是均匀填充），这样标签左端有底色、右端融进三维场景，不会切出一条硬边。

Variants

VariantUse WhenSelector
Application (data-level=3)顶层平台标签.platform-label[data-level="3"]
Intelligence (data-level=2)中层平台标签.platform-label[data-level="2"]
Data (data-level=1)底层平台标签，额外旋转 4° 以贴合倾斜的平台.platform-label[data-level="1"]

Props / Properties

PropertyTypeDefaultDescription
--label-x / --label-ylength0px由 three.js 投影结果驱动，是唯一的定位输入。
min-widthlength525px三块标签统一宽度，保证板号与标题竖直对齐。
backgroundgradientlinear-gradient(110deg,#35466d88,#36497650 60%,#31426600)右端透明收尾。
border-radiuslength19px等于 --wb-radius-panel。
transformtransformtranslate3d(var(--label-x),var(--label-y),0) translate(-50%,-50%)以锚点为中心；data-level=1 额外 rotate(4deg)，原点 12% 50%。

Accessibility

ROLE

button（由 home.js 创建 <button>，带 aria-label="Explore …"）

KEYBOARD

Tab 可达，Enter/Space 触发

SCREEN READER

由 aria-label 朗读，内部板号与标题作为可见文本补充

Do's and Don'ts

✅ Do
  • 用渐变收尾而不是硬边矩形
  • 三块标签共用 min-width，保证板号列对齐
❌ Don't
  • 不要给标签加 backdrop-filter（源码已显式设为 none，模糊会让三维平台失焦）
  • 不要让标签宽度随内容变化

Code Example

<button class="platform-label" data-level="2" aria-label="Explore Intelligence Hub"
        style="--label-x:700px;--label-y:430px">
  <span class="plate-number">02</span>
  <span><strong>Intelligence Hub</strong><small>Projects · Experts · AI Agents</small></span>
</button>
