Mode Switchmode-switch

编辑器里的三段式视图切换：整页构图 / 独立 3D / Mock-3D 对齐。

Page HeaderNav ItemMode Switch

舞台：编辑器 · 在 body[data-mode="studio"] 的字体与底色上下文中渲染。

Description

互斥的分段控件。未选中项是文字，选中项抬起到 #3a4a64 并带 1px 4px 阴影，用极轻的立面差表达“当前挡位”，而不是用高饱和色。整体容器比按钮深一档（#1c2430 对 #10151d 的页面底）。

Variants

VariantUse WhenSelector
Default编辑器顶部工具栏.mode-switch

Props / Properties

PropertyTypeDefaultDescription
paddinglength4px（容器）/ 7px 12px（按钮）容器内边距就是胶囊的呼吸空间。
gaplength3px按钮间距，比容器内边距小，形成连续轨道。
border-radiuslength7px（容器）/ 4px（按钮）两层圆角不成比例，按钮更方。
white-spacekeywordnowrap≤1180px 时收小字号而不换行。

States

StateVisualBehavior
Default按钮 11px #8fa0b6，透明背景hover 继承全局 button:hover 的 #2b394d
Activebackground #3a4a64，文字 #e6efff，box-shadow 0 1px 4px #0004切换 body[data-view]
Narrow (≤1180px)按钮 padding 收到 7px 6px，字号 10px—

Accessibility

ROLE

无 role=tablist；是三个普通 button，由 class 表达选中

KEYBOARD

Tab 逐个进入，Enter/Space 切换

SCREEN READER

朗读按钮文字；当前挡位没有 aria-selected / aria-pressed 可读

Do's and Don'ts

✅ Do
  • 容器比页面底深或浅一档，让轨道可见
  • 选中态用立面差 + 轻微阴影，不用高饱和填充
❌ Don't
  • 不要在同一个 switch 里混放图标项和文字项
  • 不要把按钮数超过 4 个（已是编辑器宽度的极限）

Code Example

<div class="mode-switch">
  <button data-view="mock">Mock-3D 对齐</button>
  <button data-view="asset" class="active">独立 3D</button>
  <button data-view="page">整页构图</button>
</div>
