# WinBrain 3D Visual Language

## Spatial Model

```
Z0 Surface
  ↓
Z1 Interactive Component
  ↓
Z2 Hero Object
  ↓
Z3 Environment
```

## Composition

- Primary object: communicates intent.
- Secondary objects: explain relationships.
- Environment: provides context only.

## Material

Each 3D asset should define:

- material type
- roughness
- emission
- transparency
- interaction response

## Motion

Motion should describe:

- trigger
- duration
- easing
- camera impact
- state transition

## Asset Contract

2D concept → 3D asset → registry → preview → runtime evaluation
